# Repair Traditions Atlas: codebook

Each tradition is scored against seven dimensions. Values are a first-pass analytic coding by the author, grounded in the cited sources (see the paper's Seed Bibliography), and flagged where provisional (`?`). The coding is a starting instrument to be validated with practitioners and curators.

Columns in `repair-traditions-atlas.csv`:

- `mode` : repair mode (Invisible / restorative; Visible / expressive; Transformative / accretive; Government records). Several traditions span more than one mode.
- `tradition_region` : name and region.
- `detectability_0_5` : 0 = undetectable, to 5 = celebrated / conspicuous.
- `skill` : Vern = vernacular/domestic; Skl = skilled amateur; Spec = specialist trade; Mast = masterly/virtuosic.
- `vitality` : Thriv / Viable / Decl(ining) / Endang(ered) / Crit(ical) / Dorm(ant) / Extinct; trend (up/down/steady); (R) = revived.
- `transmission` : Fam(ily) / Appr(enticeship) / Voc(ational) / Self / Comm(ercial). Maker coding: (f) female-domestic, (m) male-trade, (mix).
- `material_economic` : fibres (nat / syn / mix); economic model (dom = domestic-unpaid, svc = paid service, lux = luxury-restoration, art, ngo).
- `archival_status` : forms held (T textile-archive, M museum, I ICH-inventory, G government, C conservation, L living); depth (obj = object-only, tech = technique-documented, safeg = safeguarded); indexed-as-repair (y / part / n).

Sources for each tradition are listed in the paper's Seed Bibliography (clusters F and J).
